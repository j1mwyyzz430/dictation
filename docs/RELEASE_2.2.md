# 筆尖默書室 2.2 更新與還原

2.2 包含詞語按課文溫習、系統已給分先入龍虎榜、教師改分後更新同一卷。前端更新不會自動更新 Google Apps Script；正式發布狀態以 [PROGRESS.md](PROGRESS.md) 為準。

## 更新 Google 後台（原有網站）

1. 先保存目前 Code.gs，記下 Apps Script「部署 → 管理部署」中的現有版本號。本輪使用者提供的原碼已另存備份；GitHub `backup/pre-v2.2-20261016-e152ae5` 的內嵌後台與它一致（除換行格式）。此備份是程式，並非 Sheet 資料備份。
2. 網站刷新至 **v2.2** 後，以老師登入，到「網站部署」按「下載 Code.gs」或「複製 Code.gs」。檔案首行應顯示後端 v2.2。
3. 在**原來默書系統**的 Google Sheet → 擴充功能 → Apps Script，把完整新版程式貼入原 Code.gs 並保存。不要建立另一個專案，不要更換 Sheet 或部署網址。
4. 按「部署 → 管理部署 → 編輯（鉛筆）→ 版本：新版本 → 部署」。只保存編輯器內容並不會更新已部署的網頁應用程式。
5. 重新整理網站、重新登入。在老師「網站部署」確認「目前後台：2.2」。若仍顯示未確認，核對是否更新了原 `/exec` 網址對應的部署。

**不要執行 setup、setupLegacy、migrateV5、upgradeV6、resetAllStudentPasswordsTo4Digits 或其他重設／遷移函式。** 不需新增或修改任何密碼屬性。現有帳戶、PIN、課次、歷史卷及筆跡繼續沿用。

## 詞語分課設定

老師在「課次／教材」原有詞語框下，按「新增課文分組」，填各課名稱及起止位置。例如第一課是第1至7詞，第二課是第8至20詞；實際範圍按教材決定，不必每課相同數目。保存後學生在「溫習 → 詞語」可選單課、多課或全部。未分配的詞語列為「其他詞語」。改動詞語順序後須重新檢查範圍。

本輪沒有取得實際四課邊界，所以沒有代填或修改正式六年級教材。默寫、背默、隨機考試仍按原範圍，不跟隨溫習選課。

## 分數規則與驗收

- 成功交卷及檢測完成後，以已給分字計算的積分先入榜，待核字暫不給分，榜單標記暫定卷數。辨識服務失敗時仍保留待核字，不能把它們直接判對。
- 老師保存人工判定後，按新分數更新原卷；完成覆核後取消暫定標記。同一卷不重複累計。歷史未覆核且符合條件的卷也會計入。
- 零正確字、老師排除的卷、資料不完整、溫習、測試帳戶與錯字重練照舊不計榜。撤回覆核保留已保存的人工判定，重新標記暫定；要移出排名請使用「排除排名」。
- 沿用原計分權重、週榜／總榜、同分排序。新卷詞語30、句子30、段落／背默40；隨機詞語每正確字3分、句子／段落2分；舊卷仍按舊規則。
- 本機後台及瀏覽器回歸已通過；正式 Google 寫入及 iPad／Apple Pencil 未實測。老師可在自然交卷後觀察暫定標籤，改一份真實需要改分的卷後刷新榜單核對；勿為驗證而重設學生或提交假成績。

## 還原

**Google 後台**：「部署 → 管理部署 → 編輯」選回更新前記下的版本，並把編輯器內容恢復成原 Code.gs 備份，避免下次誤發布。原排名只計已覆核卷；已保存的成績及分組 metadata 仍保留。不清空任何 Sheet。舊版排名快取最多60秒，刷新或等待後再核對。

**網站前端**：回復 `backup/pre-v2.2-20261016-e152ae5` 中的 `index.html`，建立新提交並推送 main（不 force-push）。此備份保留香港楷書置中修正；不要誤用更早的 pre-centering 備份。若 main 已有2.2以後的修改，先檢查差異，只撤回2.2相關部分。

```sh
git fetch origin refs/heads/backup/pre-v2.2-20261016-e152ae5:refs/remotes/origin/backup/pre-v2.2-20261016-e152ae5
git switch main
# 確認工作目錄乾淨且沒有需保留的後續入口修改，再執行：
git restore --source=origin/backup/pre-v2.2-20261016-e152ae5 -- index.html
git diff -- index.html
# 核對後提交，循正常流程推送 main。
```

GitHub 的備份分支及附件備份皆是程式碼備份，無法替代私人 Google Sheet 資料備份。
