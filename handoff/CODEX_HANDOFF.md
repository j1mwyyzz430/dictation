## 必須先辨認版本

- 我尚未將這次附上的置中版部署到正式 GitHub Pages。

## 已有功能：維護時必須保留

以下是目前專案背景，實際 API 和細節請以讀到的最新程式核對，勿按這份文字重做一遍。

- 学生選班別、選姓名、四位數字 PIN 登入，PIN 當字串保存，0123 有效。首次設定、老師重設、停用及固定 studentId 已有；不要改回八位英數或自行增加 PBKDF2／啟用碼等流程。
- 四年級班別已由 4N 升級到 4B，仍須兼容歷史資料。6A、6B 同為六年級，共用同年級課件；grade 與 classId 不可混為一談。
- 批量匯入學生、學號排序、個別編輯／重設 PIN。
- 課次發布、封存、管理及歷史版本；多個讀默／背默段落、逐段命名、學生選指定段落。
- 溫習、聽音默寫、背默及隨機測試；詞語隨機、完整提交前不顯示默寫／背默答案。
- 粵語與標點朗讀、語速、「讀這一格」與「讀本句／小段」；背默不提供內容朗讀，不用普通話作後備。
- 手指／Apple Pencil 書寫、手掌防誤觸、擦膠、復原、清空、大小格與縮圖；保存原始筆跡。
- 本機草稿、有效計時／離開紀錄、未同步試卷保留及補交、同一試卷重試不重複入帳；不能把其他學生的試卷交到目前帳戶。

- 累積／本週榜、按年級分開、老師確認後入榜；具體積分、並列、排除／撤回覆核與時間比較以目前後端為準，本輪不改規則。

## 視覺及這次修正

- 保留暖米白、柔和色彩、WenKai 介面字體、可愛鉛筆及適量觸控動畫，也保留簡潔舒暢的操作感。不要改成冷灰白、全站系統黑體或重做另一套 UI。

## 本輪實際工作順序

1. 確認倉庫入口與發布分支，檢查工作目錄已有修改，建立本輪工作分支。
2. 列出附件與倉庫的主要差異，合併置中修正；維持後端行為和學生資料。若已有同樣修正，不重複新增覆寫層。
3. 建立／補充簡短 AGENTS.md：架構、入口、可執行驗證方式、資料保護、上述易踩錯處及 UI 偏好。另建 docs/PROJECT_HANDOFF.md 記錄現況與 API／前後端來源；docs/PROGRESS.md 記錄本輪已完成、待辦及下一步。已有這些檔案時更新，不覆蓋有用內容。勿將大型字體或所有函式抄進文件。
4. 做針對性驗證，不為這次小改跑大量無關測試。至少檢查腳本語法（含內嵌 Code.gs）、小格／大格「老、實、審、視、一」置中、換格、直橫向尺寸、右半邊落筆、草稿筆跡不被重建、默寫及背默不洩露答案。能用瀏覽器或 mock 才做；沒條件的寫明未驗證。不要在正式學生帳戶提交測試卷。
5. 檢查字體檔案與首頁/API 的載入路徑，有條件時做少量量測，將首載速度及外部字體可快取分檔方案記入待辦；本輪不實作這個較大的發布改動。
6. 完成修改及必要測試後交付 diff、分支／PR（環境支援時）和簡短更新步驟。尚未部署就明確寫尚未部署，不要直接合併到正式發布分支。因本輪只是前端修正，若實際沒有改後端，清楚告訴我 Apps Script 不用重新部署。
